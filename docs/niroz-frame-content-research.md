# Content Research: the "Niroz Frame" reel format

Sources studied: the Reels-tab screenshot and a 14.5 s screen recording of the top reel. All three uploaded copies are identical. The Facebook page itself could not be fetched from this environment.

## 1. What the page is

A Facebook creator page that posts **AI-generated, photoreal DIY/home-makeover reels**. Every video stars the same synthetic host:

- woman, long black ponytail, black baseball cap, white cropped tank with a small "NIROZ FRAME" logo, black wide-leg jeans and brown boots
- she is the brand. The outfit never changes, so the logo appears in every frame.

**Evidence that it is AI-generated:**

- the drill brand reads as garbled pseudo-text ("BAMSTES"), a classic artifact from image models
- lighting is too perfect, and surfaces are spotless mid-project
- every scene has identical framing
- each cut lasts 0.5–1.5 s, which is the typical length of an image-to-video model clip
- all the thumbnails share the same "magazine render" look

The result is hit-driven: most posts get about 20–30K views and a few break out to 10M+. The strategy is **volume plus testing**. You post many concepts, then double down on the winning themes.

## 3. Anatomy of the 104M reel (frame-by-frame)

| t (s) | Beat |
|---|---|
| 0.0–0.4 | **Hook:** a stroke of pink paint already going inside a taped heart, so it opens mid-action |
| 0.4–1.8 | Painting progress, then the tape is pulled off (a satisfying beat) |
| 1.8–3.9 | Clean pink heart reveal |
| 3.9–5.8 | Drilling floating corner shelves (drill SFX) |
| 5.8–7.9 | Installing a neon LED strip along the heart outline. The glow switches on |
| 7.9–9.9 | Gallery frames, a mirror, plants |
| 9.9–11.5 | **Final reveal:** boucle chair, rug, candles, warm light (whoosh + music swell) |
| 11.5–14.5 | **Loop:** the video returns to the empty grey corner and taping. The ending flows into the start, which drives rewatches |

- **Cuts:** 17 cuts in 14.5 s, about 0.85 s per shot.
- **Camera:** locked, wide, eye-level. It is the same angle throughout, so the room visibly "fills up".
- **Audio:** a bass-heavy music bed, "Original audio", with no voiceover. Transient hits (drill, tape rip, whoosh) are synced to the cuts.
- **Caption:** "Watch This Empty Corner Become a…" (curiosity, cut off at "more").

## 4. The repeatable formula

1. **Before → after in under 15 s, filmed from one fixed camera angle.**
2. **6–10 "progress keyframes".** Each one is a visible, satisfying step: tape, paint, drill, light on, decorate, reveal.
3. **The same character in every shot.** She is the brand mascot.
4. **"Dream-but-plausible" projects.** These are cozy, Pinterest-y, and use cheap materials: neon heart walls, bottle-glass planters, LED stair niches, tire planters and pallet carts.
5. **Seasonal hooks:** Christmas planters, Valentine's hearts and spring gardens.
6. **A loop ending and a curiosity caption.**

## 5. Production pipeline (how it's almost certainly made)

```
Idea → keyframe storyboard (8 states of the same room)
     → character reference sheet (locked identity + outfit)
     → keyframe stills (image model, edit each state from the previous one)
     → image-to-video clips (first frame → last frame, 3–5 s each)
     → trim each to 0.6–1.5 s, assemble on beat, add SFX + music
     → loop back to frame 1, caption, AI label, post
```

The key trick is **chained image editing**. Each keyframe is generated by editing the previous one ("same room, same camera, now the heart is painted pink"). That keeps the room and camera perfectly consistent. Video models then animate between adjacent keyframes.

## 7. Skills you need (human side)

- **Interior-design taste:** palettes, styling and "Pinterest" composition. Study trending decor on Pinterest and TikTok.
- **Prompt craft for edit-chaining:** keep camera and room locked, and change only one thing per step.
- **Character consistency:** keep a reference sheet, a fixed outfit and a fixed seed or reference images.
- **Rhythm editing:** cut on the beat, put an SFX hit on each cut, start mid-action and end on a loop.
- **Packaging:** curiosity captions, a thumbnail that is the final reveal, and pinned winners.
- **Analytics discipline:** track saves, shares and 3-second holds per concept, then remake the winners.

## 8. Rules and risks

- **Disclose AI.** Meta requires the "AI info" label on photorealistic AI-generated video. Turn it on when you upload. Undisclosed content risks reach penalties and audience backlash.
- **Make your own persona.** Do not copy Niroz Frame's character, name, logo or outfit. Design a distinct host and brand.
- **Monetisation:** Facebook's unoriginal-content rules reward original concepts, not re-uploads. Generate every project yourself.
- **Don't imply the build is real** or give unsafe instructions. The format is "inspiration", not a tutorial.
