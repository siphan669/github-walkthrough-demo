## Video Factory

[`video-factory/`](video-factory/) is a free, local, automated YouTube video production system built with Remotion, React and FFmpeg. It turns a script file into a finished 16:9, 9:16 or Shorts MP4. See [video-factory/README.md](video-factory/README.md) to get started.
