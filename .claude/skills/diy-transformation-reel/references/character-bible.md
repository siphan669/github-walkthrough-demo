# Host Character Bible

Fill this in once, then paste the blocks **verbatim** into every image prompt. Design an original host. Do not copy an existing creator's face, name, logo or signature outfit.

## Identity block
```
[HOST]: a woman in her late 20s, <skin tone>, <hair: colour, length, style>, <face notes: e.g. defined brows, warm brown eyes>, athletic build, natural makeup
```

## Outfit block (never changes)
```
wearing <top, colour, with small "<YOUR BRAND>" logo on chest>, <bottoms>, <shoes>, <headwear/accessory>
```
